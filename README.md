# Практическая работа №4. PHP. Основы языка, запросы и обработка HTML-форм

## Описание результата
Небольшое PHP-приложение для обработки формы заявки сотрудника и формирования списка записей из dataset. Реализовано без использования MVC.

## Используемые технологии
* PHP 8.5 (встроенный сервер)
* HTML5, CSS3
* Git

## Структура проекта
* `public/index.php` — точка входа, логика формы и вывод.
* `src/functions.php` — пользовательские функции (валидация, чтение CSV).
* `data/` — исходные файлы dataset (`employees.csv`, `form_cases.json`).

## Инструкция запуска
Требования: установленный PHP (версия 7.4+).
1. Откройте терминал в корневой папке проекта.
2. Запустите встроенный сервер:
